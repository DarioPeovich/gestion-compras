# SES Frontend Documentation

Bienvenido a la documentación del Frontend de **SES ERP**.

Esta documentación describe la arquitectura, filosofía y convenciones utilizadas para construir el nuevo Frontend del sistema.

El objetivo no es solamente documentar componentes, sino preservar las decisiones de diseño que permitieron la evolución de SES hacia una interfaz moderna sin perder la simplicidad que caracterizó al sistema desde sus comienzos.

# Objetivos del Frontend

El nuevo Frontend de SES busca cumplir cuatro objetivos fundamentales.

- Mantener la simplicidad del sistema original.
- Mejorar la experiencia visual sin afectar la productividad.
- Construir un Design System propio.
- Permitir la evolución del producto durante muchos años.
